# מרכיב הספרייה של אוצריא

כלי נייד (קובץ `.exe` אחד, בלי התקנה) שעושה דבר אחד: **מרכיב את חלקי הספרייה המפוצלים לקובץ אחד שלם**, ומאמת אותו.

## מה הוא עושה

ספריית ה-DB של אוצריא ב-[SeforimLibrary](https://github.com/Otzaria/SeforimLibrary) מתפרסמת בחלקים:

```
seforim-schema7.db.zst.part-000
seforim-schema7.db.zst.part-001
seforim-schema7.db.zst.manifest.json
```

הכלי מחבר את החלקים לפי הסדר לקובץ `seforim-schema7.db.zst` אחד, ומאמת מול `manifest.json` את ה-SHA-256 של **כל חלק** ושל **הקובץ השלם**. הקובץ המתקבל זהה בייט-לבייט למקור שלפני הפיצול.

## איך משתמשים

1. שים את `Otzaria-Library-Joiner.exe` באותה תיקייה עם קבצי `part-000`, `part-001` (ועם `manifest.json` אם יש).
2. הפעל, ובחר "בואו נתחיל".
3. הקובץ המורכב ייווצר באותה תיקייה.

אפשר גם לבחור תיקייה אחרת עם החלקים. הקריאה משם, **והכתיבה תמיד רק לתיקייה שבה הקובץ רץ**.

## ניידות

- אין התקנה, אין רג'יסטרי, אין כתיבה ל-`%TEMP%` או ל-`AppData`.
- הכתיבה היחידה היא לתיקיית ה-exe: הקובץ המורכב, קובץ זמני `*.joining` שנמחק גם אחרי שגיאה או ביטול, ותיקייה נסתרת `.otzaria-joiner-data` של רכיב התצוגה (WebView2) שנמחקת ביציאה.
- דורש Windows 10/11 עם WebView2 (מותקן כברירת מחדל ב-Windows 11 ובמרבית מחשבי Windows 10).

## דחיסה (אופציונלי)

"דחיסת קובץ לפורמט הספרייה" דוחס קובץ (למשל `seforim.db`) ל-`.zst` בדיוק כמו בניית הספרייה:

| פרמטר | ערך |
|---|---|
| רמה | `zstd -19` |
| חלון | 8MB (ברירת המחדל של רמה 19) |
| סכום ביקורת (xxh64) | פעיל |
| גודל תוכן בכותרת | כן |

הפרמטרים נלקחו מקוד הבנייה של SeforimLibrary ואומתו מכותרת הקבצים המפורסמים.

## בנייה

```
cargo build --release -p otzaria-joiner --features custom-protocol
```

בדיקות: `cargo test -p joiner-core`. הבנייה של ה-exe רצה אוטומטית ב-GitHub Actions ומתפרסמת כ-Release בתיוג `v*`.
